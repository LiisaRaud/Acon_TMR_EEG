# Encoding and sleep oscillations during TMR

Code accompanying:

> Raud, L. 2026 *Sleep EEG distinguishes learned from novel auditory cues without predicting memory retention in a targeted memory reactivation study*. Preprint

## Overview
Accompaning scripts for the manuscript.

## Contents
- `EEGprocessing` – scripts for EEG analysis, including preprocessing, time-frequency analysis, extraction of averaged time-frequency windows, topographic analysis, visualization
- `sleepscoring/` – automatic sleep scoring (YASA), merging sleep EEG with behavioral data, and calculation of sleep macroarchitecture
- `statistics/` – statistical analysis

## Requirements
- R 4.4 / Python 3.11 / MATLAB >R2024b
